# ВЕДРА

[Виджет для OBS](https://artemkisel841-png.github.io/vedra-budget/) · [Форма изменения суммы](https://github.com/artemkisel841-png/vedra-budget/actions/workflows/update-budget.yml)

В OBS добавьте источник «Браузер» и вставьте адрес виджета. Исходный размер — 700 × 369 px. Уменьшайте источник пропорционально.

Модератору нужен аккаунт GitHub с правом записи в этот репозиторий. В форме нажмите **Run workflow**, выберите действие **Установить**, **Прибавить** или **Вычесть**, введите целые рубли и запустите операцию. Для первой записи используйте **Установить**. В прибавлении и вычитании указывайте положительное число.

Сумма сохраняется в `budget.json` в ветке `budget-data`. При открытии или обновлении виджет сначала получает подтверждённое значение через GitHub API. Затем он проверяет файл каждые 12 секунд и дополнительно сверяется с API каждые 75 секунд. Появление суммы в уже открытом OBS может занять около минуты после завершения операции. История сумм доступна в публичной истории ветки. При временной недоступности GitHub уже открытая страница продолжает показывать последнее прочитанное значение.
